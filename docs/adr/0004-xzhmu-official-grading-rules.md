# 成绩域模型对齐徐州医科大学官方规则

**状态**：已接受

## 背景

应用的 GPA 计算原本使用通用公式 `(成绩−50)/10` 且无下限：不及格成绩会算出负绩点拉低 GPA；另有一条无出处的「< 10 分仍计入 GPA、仅标记」特殊分支。经核查《徐州医科大学本科生学籍管理规定》（徐医大办〔2016〕44号，[信息公开网原文](https://xxgk.xzhmu.edu.cn/info/1041/1062.htm)），应用语义与校方规则存在多处偏差。

## 决策

成绩域模型以徐医官方规则为准：

1. **绩点换算**（第十二条）：百分制成绩 ≥ 60 → 绩点 = (成绩−50)/10；< 60 → 绩点 0。无负绩点。
2. **Grade 语义**（第二十五条）：重修课程以历次考试最高分记录；应用只保存这一个有效分，不记录多次成绩。
3. **补考**（第十五条）：补考及格成绩以 60 分计。
4. **范围**：应用只跟踪学位课程；徐医学位课程均为百分制，五级制（A–E）不在范围内。
5. **课程身份**：课程名在 profile 内唯一，即为课程键——徐医培养方案中同名课程均带数字后缀（诊断学1/诊断学2），无需引入内部 ID。
6. 原「< 10 分」特殊分支在计算层删除：任何 < 60 的成绩一律按校规记 0 绩点，不再有特殊分支。UI 层保留 < 10 分「疑似误输入」标记，仅作录入提示，不影响计算。

## 考虑过的选项

1. **保留通用公式（含负绩点）**——否决：与校规直接矛盾，算出的 GPA 低于教务核算值，对「离毕业线还差多少」的核心问题是错误答案。
2. **支持五级制课程**——否决：学位课中不存在非百分制课程（用户确认），引入只会增加无回报的复杂度。
3. **为课程引入内部 ID**——否决：校规保证名称唯一性，ID 是纯成本；若未来支持外校/其他专业再重新评估。

## 后果

- `calculateGPA` 中 gradePoint 对 < 60 取 0；`useGPA` 的 `illegalGrades`（< 10）由「不及格课程」语义取代。
- 已录入不及格成绩的历史数据，GPA 显示值会上升（负绩点 → 0）——这是修正，不是回归。
- 若未来面向外校用户，本 ADR 的全部前提（官方表、名称唯一性、百分制）都需要重新核查。
