# UI 改版：新粗野主义 + 大字移动优先，双主题下 ink 翻转

**状态**：已接受

## 背景

界面需要一次视觉、交互与样式的整体改版。核心场景是 PWA 下「掏出手机录成绩、看一眼 GPA 离目标差多少」，因此骨架定为大字移动优先：GPA 数字巨号化、大触控区。视觉风格定为新粗野主义（粗实线边框、无模糊硬阴影、高饱和平涂色块）。保留已有 auto/light/dark 三态主题，但新粗野主义的签名「黑色边框 + 黑色硬阴影」在深底上会消失，这是该风格与 dark mode 的天然矛盾。

## 决策

1. **色板双主题，中性色翻转、彩色不动**。`--ink` 单 token 同时供给边框、硬阴影与正文文字：light 主题 `#1A1A1A`，dark 主题翻转 `#FFF6E5`；`--accent`/`--signal`/`--danger` 两主题共用（danger 深色下略提亮）。硬阴影统一 `4px 4px 0 var(--ink)`，按压态 `2px 2px 0` + 位移，无模糊无透明度。
2. **字体**：中文走系统栈；数字（GPA 是视觉主角）内嵌 Archivo Black 子集（仅 `0-9.` 约 11 字形，KB 级成本）。字重：数字 900、标题 800、正文 400/500。
3. **信息架构**：三 tab 骨架（计算/统计/我的）不动，只重排页面内部；目标分析卡从统计页上提到首页 GPA 巨号旁。
4. **样式架构**：`styles.css` 只含 CSS 变量与 `.neo-card`/`.neo-btn`/`.neo-input` 等签名类（封装边框+阴影+按压，variant 用 `--danger` 修饰类表达）；组件布局写各自 `<style scoped>`；清除全部组件内联样式。
5. **杂项**：导航 emoji 图标换粗描边内联 SVG；两个图表按新色板重涂，不改类型与交互；删除根目录无引用的 `css/` pico 文件。
6. **实施**：新分支三批走——① 换 token ② 建签名类并清内联样式 ③ 逐页重排（首页→统计→我的），每批独立可验可回滚，完成后合并。

## 考虑过的选项

1. **砍掉 dark mode 只做浅色**——否决：dark mode 是已交付且有测试覆盖的功能，砍掉是倒退；ink 翻转用变量即可解决，成本一次性。
2. **深色主题弱化边框/阴影做妥协版**——否决：深色下不再是新粗野主义，两主题气质分裂。
3. **合并计算+统计为一页仪表盘**——否决：录入与浏览互相干扰；三 tab 分工（录入/分析/配置）本身是干净的。
4. **引 UnoCSS/Tailwind**——否决：新粗野主义签名重复度极高，三四个共享类即可覆盖，原子类反而啰嗦且加构建依赖。
5. **全站 webfont（含中文）**——否决：中文字体子集化后仍数百 KB，为装饰付出真实性能代价不值；仅数字子集化收益/成本比最高。

## 后果

- 既有 `tests/components/theme-variables.test.js` 断言的 token 名（`--accent-soft` 等）将随新色板更名/调整，测试需同步更新。
- 任何组件只要使用 `--ink` + `.neo-*` 签名类即自动获得正确双主题；绕过体系手写颜色会破坏该保证。
