# 深色模式根因修复 + Supabase 全量移除

Status: ready-for-agent
Date: 2026-08-30
Decides: ADR-0002（移除云同步，取代 ADR-0001）

## Problem Statement

学生用户在深色模式下打开应用时，页面背景与正文仍是浅色主题的颜色（卡片是深的、整页是白的），且每次刷新先白闪一下再变回来；手动切换主题时浏览器地址栏颜色也不跟随。同时，应用每次改动都向云端推送数据、启动时发起网络请求，但这些数据因匿名身份绑定在单个浏览器上永远无法在别的设备找回——云集成对用户可感知的价值为零，只带来写放大、启动延迟和故障面。

## Solution

深色模式按根因修复：主题属性挂到文档根元素，让全局背景/文字变量真正级联；Vue 挂载前用内联脚本预设主题消除白闪；浏览器主题色跟随实际生效主题；图表刻度与网格随主题取色。云集成整体移除（同步引擎、匿名认证、分享码、埋点、异常上报、依赖、密钥、数据库迁移目录全部删除），应用回归纯本地（localStorage）+ JSON 导入导出的离线形态。

## User Stories

1. 作为学生用户，我想切换到深色模式后整个页面（背景、正文、卡片、输入框、导航）都是深色，而不是只有卡片变深、页面还留着白底。
2. 作为深色模式用户，我想刷新页面时不先看到一片白色闪烁，打开即是正确的深色。
3. 作为跟随系统的用户，我想在系统切换深浅色的瞬间，应用无需刷新就跟着切换。
4. 作为深色模式用户，我想让浏览器地址栏/状态栏颜色与应用实际主题一致，而不是永远跟随系统。
5. 作为学生用户，我想在深色模式下看清统计页图表的坐标轴刻度和网格线。
6. 作为学生用户，我想在深色模式下看到档案列表中"使用中"的高亮与文字仍然清晰可辨。
7. 作为学生用户，我想应用完全不发起任何网络请求也一切正常——成绩录入、GPA 计算、目标分析、统计图表全部离线可用。
8. 作为学生用户，我想通过 JSON 导出/导入在设备间迁移我的档案（Profile）与成绩（Grade）数据。
9. 作为学生用户，我不想在界面上再看到"立即同步""生成分享码""通过分享码恢复"这些做不到承诺的入口。
10. 作为学生用户，我不想因为后端服务不可用而看到同步失败的报错横幅。
11. 作为曾经被写入过云端会话的老用户，我想升级后浏览器里残留的匿名会话数据被自动清掉，不留死数据。
12. 作为维护者，我想依赖列表里不再有 Supabase SDK，安装体积与构建产物显著变小。
13. 作为维护者，我想 `.env` 里不再有云服务密钥，泄露面归零。
14. 作为维护者，我想测试套件不再需要 mock Supabase，跑得更快更稳。
15. 作为维护者，我想仓库里不再有 `supabase/` 迁移目录和双分支启动逻辑，启动路径一条直线。
16. 作为维护者，我想领域核心（GPA 计算、解析器、学期排序）的行为在此过程中完全不变，现有测试继续通过。
17. 作为已落盘数据的用户，我想升级后本地 `gpa_v2` 存储格式不被破坏，成绩与档案原样保留。

## Implementation Decisions

- 主题状态仍由 app store 持有（auto/light/dark 三态 + 系统偏好监听），但解析结果的 DOM 落点从 `#app` 内层 div 改为文档根元素（`documentElement`），使 `body` 上的背景/文字变量正确级联。
- `index.html` 加载 Vue 前执行一小段内联脚本：从 localStorage 读出持久化的主题偏好，解析后立刻在根元素上设置主题属性，消除首帧白闪。
- `theme-color` meta 从"跟随系统的双 media 标签"改为单一标签，由主题逻辑在主题解析结果变化时动态写入实际生效的颜色。
- 两个图表组件（学期 GPA 趋势、成绩分布）的坐标轴刻度文字与网格线颜色改为随主题解析结果取值（深浅两套固定色值，与 CSS 变量保持一致），数据柱色沿用现有品牌色（两种背景下均可读）。
- 档案列表"使用中"的高亮背景与文字色从硬编码浅绿色改为 CSS 主题变量，深色主题给出对应配色。
- 移除整个云集成：Supabase 服务层（客户端/匿名认证/同步/埋点/异常上报/分享码）、同步引擎与端口抽象、状态合并模块、同步/埋点组合式函数、同步状态条与分享码/恢复对话框组件及其全部测试、`supabase/` 目录、SDK 依赖、环境变量。
- 启动流程从"配置了云服务与否"的双分支简化为单一路径：加载本地状态（含 legacy 迁移）→ 挂载应用。
- 各组件中的埋点调用（主题切换、成绩录入、档案切换/新建、导入导出）随埋点模块一并删除，组件只保留领域行为。
- 档案页移除"云同步与分享"卡片。
- 应用启动时清理 localStorage 中遗留的 Supabase 会话键（`sb-` 前缀）。
- `Grade`/`Profile` 数据结构中的 `updatedAt` 字段保留写入不动：v2 存储格式已落盘，保持向后兼容（依据 ADR-0002）。
- 词汇表与 ADR 已同步：`Grade` 定义不再提及同步合并；ADR-0002 取代 ADR-0001。

## Testing Decisions

- 好的测试只断言外部行为（组件渲染出的 DOM、store 暴露的状态），不断言内部实现细节。
- 主题系统：沿用现有组件测试形态（@vue/test-utils 挂载 + jsdom），新增 app store 的主题测试——设置 `theme` 后断言文档根元素的主题属性被正确设置，auto 模式下跟随 mocked 的 `matchMedia` 结果。
- 移除工作：不新增测试，验收靠三件事——现有测试套件全绿（证明领域核心未受影响）、全局搜索无对已删模块的残留引用、生产构建成功。
- 先例：`tests/components/*.test.js`（组件挂载断言 DOM）、`tests/utils/*.test.js`（纯函数）、`tests/setup.js`（localStorage polyfill 与环境垫片）。
- Supabase 相关的 10 个测试文件随被测模块一起删除，不做"留尸"式保留。

## Out of Scope

- UI 视觉重设计（配色体系、布局、组件结构基本沿用）。
- 任何新的分享/跨设备机制（URL 分享、P2P 等）。
- v2 存储格式变更或 `updatedAt` 字段下线。
- 领域核心（GPA 计算、解析器、学期排序）的任何行为变更。
- PWA/Service Worker 配置调整。
