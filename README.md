# xhzmu-mz-GPA

徐州医科大学 GPA 计算器。Vue 3 + Pinia + Vite 构建的 PWA，绩点口径以学校官方规则为准（见 `docs/adr/0004`）。

## 开发

```bash
npm install
npm run dev      # 本地开发
npm test         # vitest
npm run build    # 产物构建
```

## userscripts/ — 教务成绩 GPA 统计（油猴脚本）

`userscripts/jwpt-gpa.user.js`：在教务系统「学生成绩查询」页（`jwpt.xzhmu.edu.cn/cjcx/cjcx_cxDgXscj.html`）自动完成全量查询并就地统计。

**功能**

- 打开页面后自动把「学年 / 学期 / 课程标记」置为全部、一次取回全部记录并查询
- 悬浮统计面板：GPA、学位 GPA、加权/算术平均分、已获/已修学分、学位学分、最高/最低分（带课程名）、不及格门数、分数分布
- 同一课程多次修读按最高分去重（对齐校规 ADR-0004）；绩点直接采用教务网格官方值
- 网格任何变化（手动查询、排序、翻页、调整列）都会自动重算，也可点面板「重算」

**安装**

1. 浏览器安装 Tampermonkey 扩展
2. 把 `userscripts/jwpt-gpa.user.js` **拖进浏览器窗口**，在油猴安装页确认（推荐此方式，按原始字节安装；复制粘贴可能被中间环节改写源码）

**使用**

- 登录教务系统，进入 信息查询 → 学生成绩查询，等一秒左右面板自动出现
- 面板可收起成浮动按钮，点按钮重新展开
- 异常排查：控制台执行 `__jwGpa.debug()`，输出版本、解析路径、原始字段与统计快照

**口径说明**

- 学位课程 = 网格「是否学位课程」列为「是」
- 已获学分只计及格课程（教务绩点 > 0，或百分制 ≥ 60，或合格/通过类文本）
- 非百分制（等级制）成绩不参与均分/最值/分布，单独计数
